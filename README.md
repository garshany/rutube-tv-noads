# Rutube TV без рекламы — мод для TizenBrew

Мод для [TizenBrew](https://github.com/reisxd/TizenBrew) на телевизорах Samsung (Tizen).
Открывает **официальный телевизионный веб-интерфейс Rutube** (тот, что грузят их ТВ-приложения)
и убирает из него видеорекламу. Интерфейс, поиск, вход по QR, подписки и плеер — родные Rutube.

> ⚠️ **Не протестировано на телевизоре Samsung.** Проверено только в Chrome на Mac
> (через отладчик, так же, как TizenBrew подмешивает скрипт). Работа внутри TizenBrew на
> реальном ТВ, все кнопки пульта и срезание *живой* рекламы пока не подтверждены — см. ниже.

## Установка

1. Поставьте TizenBrew (режим разработчика, Host PC IP `127.0.0.1`).
2. В TizenBrew нажмите **зелёную кнопку** и добавьте GitHub-модуль `garshany/rutube-tv-noads@main`.
3. Запустите **Rutube TV** из списка модулей.

## Как работает

- **Какой интерфейс.** У Rutube для телевизоров нет отдельных приложений — их пакеты
  `.wgt` (Samsung) и `.ipk` (LG) лишь открывают веб-страницы на rutube.ru. Samsung-версия
  (`/tv-release/tizen.server/tizen/`) играет видео только через `webapis.avplay`, а у TizenBrew
  нет разрешения на этот плеер. Поэтому мод открывает LG-версию
  (`/tv-release/webos.server/webos/`): она играет обычным `<video>` + MediaSource и работает
  в любом браузерном движке, включая Samsung.
- **Реклама.** Список рекламных вставок (VAST: преролл, мидроллы, постролл) приходит полем
  `advert` в ответе `GET /api/play/options/<id>/`. Мод перехватывает `JSON.parse` и
  `Response.prototype.json` и обнуляет `advert`, `meta.advert_rule_id`,
  `meta.advert_limit_rule_id` у объекта параметров видео. Остальные данные не трогаются.
- **Автозапуск.** Плеер LG-версии сам вызывает `video.play()`; если движок запрещает
  звук без нажатия (`NotAllowedError`), видео стояло бы с вечной заглушкой. Мод тогда
  запускает его без звука и включает звук при первом нажатии на пульт.
- **Пульт.** LG-версия ждёт коды кнопок LG. Совпадают все, кроме «Назад» (Samsung 10009 →
  LG 461) и общей кнопки «Пуск/Пауза» (Samsung 10252 → LG 415/19) — мод их переводит.

## Что проверено (Chrome 155 на macOS)

- Интерфейс Rutube открывается, видео 1080p играет.
- Ответ `play/options` доходит до приложения без рекламных полей; поддельный ответ с
  `advert` очищается по обоим путям разбора; объекты без `video_balancer` не меняются.
- «Назад» с кодом Samsung (10009) возвращает из видео на главную.
- При запрете автозапуска со звуком видео стартует без звука, звук включается кнопкой.

## Что НЕ проверено

- Работа на телевизоре Samsung внутри TizenBrew (другой, более старый веб-движок).
- Срезание реальной рекламы: из места проверки Rutube рекламу не присылал вовсе
  (`advert: null`), поэтому проверка была на синтетическом ответе. Если Rutube вставляет
  рекламу другим путём, мод его не закроет.
- Кнопки пульта, кроме «Назад»; кнопка «Пуск/Пауза».
- Платёжные разделы, прямые эфиры, вход по QR внутри TizenBrew.

## Важно

Блокировка рекламы противоречит правилам Rutube; используйте на свой риск. Rutube может
в любой момент изменить свой интерфейс или API — мод тогда перестанет работать.
Мод не содержит кода Rutube и не изменяет их приложения: он лишь открывает их публичную
страницу и правит данные в памяти браузера.
