# Rutube TV без рекламы — мод для TizenBrew (Samsung Tizen)

Мод для [TizenBrew](https://github.com/reisxd/TizenBrew), который открывает на телевизоре Samsung
**официальный телевизионный интерфейс Rutube** и убирает из него видеорекламу. Интерфейс, поиск,
разделы, вход по QR-коду, подписки и история — родные Rutube; мод не содержит их кода и не
изменяет их приложения.

## Где проверено

| | |
|---|---|
| Телевизор | Samsung **QE55Q80A** (2021, платформа `21_NIKEM2`) |
| ОС | **Tizen 6.0**, веб-движок Chromium 76 |
| TizenBrew | установлен через TizenBrewInstaller v1.1.3 (macOS) |
| Мод | **0.1.4** — видео играет, интерфейс и пульт работают |

## Установка

### 1. Режим разработчика на телевизоре
1. Откройте **Apps** (Приложения) и наберите на пульте **1 2 3 4 5**.
2. Включите **Developer mode**, в **Host PC IP** впишите IP своего компьютера (для установки),
   нажмите OK.
3. Перезагрузите телевизор: удерживайте кнопку питания на пульте до логотипа Samsung.

### 2. TizenBrew
1. Скачайте TizenBrewInstaller для своей ОС со страницы
   [releases](https://github.com/reisxd/TizenBrewInstaller/releases) и запустите его
   (на macOS/Linux перед запуском: `chmod +x <файл>`).
2. Укажите IP телевизора (Настройки → Общие → Сеть → Состояние сети → Настройки IP).
3. Выберите **Install TizenBrew**. На Tizen 7+ установщик попросит войти в аккаунт Samsung
   для сертификата.
4. После установки снова откройте режим разработчика (Apps → 12345) и впишите в Host PC IP
   **`127.0.0.1`** — так TizenBrew может подключать моды. Перезагрузите телевизор тем же способом.

### 3. Мод
1. Откройте **TizenBrew** и нажмите **зелёную кнопку** — откроется менеджер модулей.
2. Выберите **«Добавить модуль с GitHub»** и введите:
   ```
   garshany/rutube-tv-noads@main
   ```
   jsDelivr (через него TizenBrew скачивает модули) кэширует `@main` до 12 часов. Если после
   обновления мода на телевизоре осталась старая версия, удалите модуль и добавьте его с
   конкретным коммитом, например `garshany/rutube-tv-noads@b4b888faf3e9` (версия 0.1.4).
3. Запустите **Rutube TV** из списка модулей. Войти в аккаунт можно в профиле по QR-коду.

Если видео не начинает играть 6 секунд, мод сам покажет зелёную панель диагностики (версия мода,
состояние плеера, последние ошибки). **Красная кнопка** пульта показывает и скрывает её вручную.

## Как это устроено

У Rutube для телевизоров нет «настоящих» приложений: их пакеты `.wgt` (Samsung, 14 КБ) и `.ipk`
(LG, 13 КБ) лишь открывают веб-страницы на rutube.ru. Мод работает так же, как TizenTube с
`youtube.com/tv`: TizenBrew открывает страницу и подмешивает в неё `dist/userScript.js`.

1. **Какую страницу открываем.** Samsung-версия (`/tv-release/tizen.server/tizen/`) играет видео
   только через плеер Samsung `webapis.avplay`, а у TizenBrew нет разрешения на него — видео не
   стартует. Поэтому мод открывает LG-версию (`/tv-release/webos.server/webos/`) — тот же
   интерфейс, но обычный `<video>`.
2. **Реклама.** Список вставок (VAST: преролл, мидроллы, постролл) приходит полем `advert` в ответе
   `GET /api/play/options/<id>/` и разбирается функцией `parseAdverts`. Мод перехватывает
   `JSON.parse` и `Response.prototype.json` и обнуляет `advert`, `meta.advert_rule_id`,
   `meta.advert_limit_rule_id` у объекта параметров видео; остальные данные не трогаются.
3. **Видео через hls.js.** LG-версия отдаёт поток (`<source src="…m3u8">`) встроенному HLS-плееру.
   На Samsung он отвечает `canPlayType` «maybe», загружает описание потока, но кадров не отдаёт
   (`readyState=1`, `0x0`, вечный `waiting`). Мод забирает HLS-ссылки у `<source>`/`<video>` и
   проигрывает их через [hls.js](https://github.com/video-dev/hls.js) 1.4.14 (ES5-сборка, подходит
   Chromium 76) поверх MediaSource. CDN Rutube разрешает такие запросы для rutube.ru (CORS).
4. **Автозапуск.** Если движок запрещает звук без нажатия (`NotAllowedError`), видео стартует без
   звука, а звук включается первой кнопкой пульта.
5. **Пульт.** LG-версия ждёт коды кнопок LG. Совпадают все, кроме «Назад» (Samsung 10009 → LG 461)
   и «Пуск/Пауза» одной кнопкой (Samsung 10252 → LG 415/19) — мод их переводит.
6. **Выход.** Кнопка «Выйти» в LG-версии зовёт `webOS.platformBack()`, на Samsung это ничего не
   делает. Мод подменяет её на выход из приложения Tizen (`tizen.application…exit()`), иначе
   `window.close()`.

## Важно

Блокировка рекламы противоречит правилам Rutube; используйте на свой риск. Rutube может в любой
момент изменить интерфейс или API — тогда мод перестанет работать или потребует обновления.
